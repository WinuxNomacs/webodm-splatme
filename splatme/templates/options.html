How long the trainer works on the model. It grows the model in the first half of the steps, up to step 15,000 unless Grow Until says otherwise, then refines it.
The photos' longer side in pixels as the trainer sees them. Larger photos are scaled down whole, so each keeps its full view: nothing is cropped, only fine detail is lost. GPU memory depends on it most: lower it when the GPU runs out of memory. Blank keeps the photos as they are.
The most gaussians the model may grow to, a limit for very large scenes. When the GPU runs out of memory, lower Image Size first.
How much a gaussian's colour may change with the direction it is seen from: 0 the same from every side, 3 the most (shine, reflections), for a larger model and more GPU memory.
How the trainer adds, moves and removes gaussians. MCMC keeps the model within Max Gaussians, moving them to where the photos need detail.
The trainer learns each photo's brightness and colour apart from the model, so light that changed between photos does not end up in it. The 3D view shows the model without them: it can look a little brighter than the photos' edges. On by default with MRNF, off with MCMC and IGS+, as in LichtFeld Studio.
The step the model stops growing at: until then the trainer adds gaussians where the photos show detail the model lacks. Later can give large scenes more detail, for more GPU memory and time. From 1,000 to 3,000 less than Steps.
For a task processed with a boundary (a GeoJSON file): the splats outside it are left out, as they are of the point cloud and the mesh.
For photos that show the sky: the training leaves it out, so it does not become haze around the model. Finding it takes a few minutes more.
For DJI Thermal Analyzer's tasks: the colours the temperatures are drawn in, which the model shows. They run from the task's coldest to its hottest, the same in every photo.
