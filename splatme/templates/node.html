Set Up a Splat Node

The splat node trains the splats, in a container on a machine with an NVIDIA GPU (GTX 16 or RTX 20 to RTX 50 series). That machine needs the GPU's driver, Docker with Compose v2, and the NVIDIA Container Toolkit. The install downloads the node's image (4 GB; 6.6 GB once unpacked), checks the GPU and starts the node; run it in a terminal on that machine. The node trains with OpenSplat; add --trainer lichtfeld to train with LichtFeld Studio instead.

  • On WebODM's Machine
  • On Another Machine
  • A Node Installed Before SplatMe
curl -fsSL https://github.com/WinuxNomacs/webodm-splatme/releases/latest/download/splatnode.sh | bash -s install

The node joins WebODM's network and saves its address and token here: reload this page when it is done. With several WebODMs on the machine it names them; add --webodm <its webapp container>.

curl -fsSL https://github.com/WinuxNomacs/webodm-splatme/releases/latest/download/splatnode.sh | bash -s install --standalone

It prints the node's address and token: enter them below, press Test Connection, then Save. The node listens on port 3100 (--port for another) over plain HTTP: let only WebODM's machine reach that port, or put an HTTPS proxy in front of it.

curl -fsSL https://github.com/WinuxNomacs/webodm-splatme/releases/latest/download/splatnode.sh | bash -s connect

On WebODM's machine, after SplatMe is installed and WebODM restarted.

Upgrade and uninstall are the same command with upgrade or uninstall; more in SplatMe's documentation.
