SplatMe

Trains a task's Gaussian splats on a splat node: a container with a GPU that runs beside WebODM. Training starts from Train Splats in a completed task's panel on the Dashboard, or by itself when a task created with New Task With Splats completes.

New Task With Splats

New Task With Splats, beside Select Images and GCP in a project on the Dashboard, opens WebODM's New Task panel with SplatMe's panel above it: Train Splats When Completed, ticked, with the options here. The task is then trained by itself when it completes processing, and again each time it is processed again. A task's Edit Task panel has SplatMe's panel too, to change them or switch the training on or off.
